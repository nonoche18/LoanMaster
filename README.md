# LoanMaster
Speeding up loan process for BOFA clients 
Option A: Getting faster, clearer answers on loans 

Businesses applying for a loan may wait weeks for a decision and often don’t know how much they could borrow or what might hold them back.  

Solution - Create Lender Profiles, comparison scores, simplifying financial information and loan process for mid sized businesses. 

- Interactive profiles (Picture, Bio, Specialties, and others)  https://bankerlocator.bankofamerica.com/?q=11363 based off this website and verified outside information to determine compatibility  

- Comparison percentage match 

Provides an initial financing estimate, an online application, document upload, and application status updates (Make it like an aesthetic roadmap), why companies finances enable to get the loan, or maybe why it would hinder the companies chances.
